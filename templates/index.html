About This Project

AI Public Safety Video Monitor combines Computer Vision (YOLOv8 + ByteTrack) with a dedicated weapon-detection model to track people and flag armed individuals in video footage or a live camera feed. Detections are confirmed across multiple frames before an alert is raised, to reduce false positives.

Tools Used

  • YOLOv8 (person/object detection) + ByteTrack (tracking)
  • Dedicated gun/knife detection model
  • Flask (Backend Framework)
  • HTML, CSS, JavaScript (Frontend)

Key Features

  • Persistent Person IDs across an entire video
  • Temporal confirmation before raising a weapon alert
  • Confirmed threats highlight both the weapon and the associated person
  • Live webcam detection alongside video upload
